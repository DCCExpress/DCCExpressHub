Movement help

Movement describes how a locomotive travels along a selected physical route using blocks, segments, turnouts, sensors, events and actions.

1. Route selection

Movement always uses one concrete generated physical route, including source, intermediate and destination blocks, track sections, turnout passages and travel direction.

2. Route vector

The route vector shows physical resources in execution order. Blocks, segments and turnout passages may appear separately. Click an item to edit its detailed settings.

3. Blocks and block types

Through blocks are normally passed without stopping. Station blocks are natural stopping points. New Movements get a default 10 second fixed plus 0–5 second random delay at BEFORE DEPART for station blocks.

4. Conditions and events

Blocks can have separate APPROACH, ARRIVED, DEPART and LEAVE sensor conditions. Without a custom condition, Movement uses its built-in default such as the block occupancy sensor for ARRIVED.

5. Action events

APPROACH runs before arrival. ARRIVED belongs to arrival processing. BEFORE DEPART runs after arrival while stopped. DEPART runs as departure begins. ENTER / LEAVE belong to physical resources. AFTER LEAVE runs after the block is fully cleared.

6. Actions

Actions can set speed, control locomotive functions, pulse the horn, wait for fixed or random time, play audio or write log messages.

7. Blocking and background sequences

A Blocking sequence must finish before Movement continues. A Background sequence runs in parallel and should be used for effects that must not hold the train.

8. Safety sensors

Before a leg starts, physical safety sensors can be checked. Sensors expected to be free must have a known OFF state. Ignore a sensor only when the current train is legitimately expected to occupy it.

9. Rolling reservation

For A1 → B1 → C1, only the section needed for A1→B1 should be checked and reserved first. B1→C1 is handled later, preventing unnecessary blocking of other trains.

10. Example: station stop

The train arrives at a station block. ARRIVED actions run first. Then BEFORE DEPART runs while stopped, including the default 10 second plus random 0–5 second blocking wait. DEPART follows only after that sequence finishes.
