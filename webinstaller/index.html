Web Installer & Serial Configurator

Install, recover, configure and diagnose DCCExpressHub directly from Chrome or Edge.

SERIAL OFFLINE NO PROTOCOL
This tool requires desktop Chrome or Microsoft Edge with Web Serial support. GitHub Pages HTTPS is supported directly.

Firmware installer

Uses the same esp-web-tools installer model as DCCExpressLite. No local helper server, Node.js, PlatformIO or esptool installation is required on this PC.

The installer itself asks you to choose the Hub USB serial device. There is no separate COM-port selector.

Serial configuration

Connect to the firmware at 115200 baud. If the Hub is rebooting or running an older firmware without the configuration protocol, the serial connection remains open in recovery mode instead of disconnecting.
